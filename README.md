# Movie Recommender System

Content-based movie recommendation engine with ETL pipeline, SQLite storage, and Streamlit demo.

## Overview

- Content-based filtering using CountVectorizer and cosine similarity on TMDB 5000 Movies dataset
- ETL pipeline: extract, transform, load into normalized SQLite database
- SQL queries for genre analysis and movie statistics
- Multi-format export: CSV, JSON, Parquet
- Interactive Streamlit app: recommend by title or by free-text interest

## Dataset

Download `tmdb_5000_movies.csv` from Kaggle:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

Place it in a folder named `data/`.

## How to run

**Option 1 — Local**

1. Install dependencies
```
pip install -r requirements.txt
```

2. Run the notebook to generate model files
```
jupyter notebook Movie-recommender.ipynb
```
> Note: `similarity.pkl` and `vectors.pkl` are not included in this repo due to file size (>25MB).
> It will be generated automatically when you run the notebook.

3. Launch the app
```
streamlit run app.py
```

**Option 2 — Google Colab**

Run all cells including the last two (pyngrok setup).
Replace `NGROK_TOKEN` with your token from ngrok.com.
A public URL will be printed to access the app in your browser.
